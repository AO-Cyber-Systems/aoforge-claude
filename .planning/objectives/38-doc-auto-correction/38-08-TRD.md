# TRD 38-08: Migration 0007 — fix stale command references in projects

<objective>
Projects carry DevFlow-authored text that names retired commands: CLAUDE.md DEVFLOW blocks written
by earlier map-codebase runs, and STATE.md files. Fix those mechanically through the objective-36
runner, which provides backup, stamping, notices and a session-start commit. Never touch historical
records.

Resolved intent: kind=plugin, work=feature, tdd=strict, test_list_first=required,
fixture_strategy=generators. Constraints honored: `no_llm_test_data`, `no_property_based_default`,
`no_gherkin_layer`.
</objective>

## Runtime model (binding)

- Migration contract: synchronous detect/apply. Changed paths are relative posix. The migration does no backup of its own, because the runner backs up to `~/.claude/devflow/backups/` before the first write.
- Fixtures come from `__fixtures__/upgrade-fixtures.cjs` (`makeFakeHome`, `makeV1Project`, `makeStampedProject`) plus hand-written files. Every call passes `userHome` = a fake home. **Never read or write the real `~/.claude` or a real repo.**
- Commit via `node ~/.claude/devflow/bin/df-tools.cjs commit "<msg>" --files <paths>`. If signing fails, STOP; never bypass. One plain command per Bash call. Never use port 8080. No version bump, tag or push.

<codebase_examples>
Shape to mirror: `migrations/0005-claude-md-block.cjs` (detect/apply; ManagedBlockError handling) and
`migrations/0002-job-to-trd.cjs` (`SESSION_LOG_RE = /^##\s+Session Log[^\n]*$/m`,
`withSessionLogLine(content, line)`; it returns null when there is no Session Log section).

In-place block rewrite (preserves marker attrs; this is why it does not use `upsert`, which re-renders the markers):

```js
const block = managedBlock.read(text);            // throws ManagedBlockError on malformed
if (block) {
  const region = text.slice(block.start, block.end);
  const r = docRefs.rewriteText(region);
  next = text.slice(0, block.start) + r.text + text.slice(block.end);
}
```

STATE.md: `split = SESSION_LOG_RE.exec(content)`. Rewrite `content.slice(0, split.index)`. The
Session Log runs from `split.index` to the next `^## ` heading (or EOF): keep it verbatim, and
rewrite any later sections. Then append the log line inside the log section, after its last
non-blank line.
</codebase_examples>

<gotchas>
- 38-09's CI gate scans `bin/**/*.cjs` source, comments included. Never write a literal stale token such as `/df:health` in this module's comments or strings. Write `/df:<name>` or describe it in words. Test files are exempt.
- 0005 (id order) runs first in the same `apply`. The runner re-detects each migration just before it runs, so 0007 sees 0005's output. Test 13 proves the two do not fight: the template's rules text contains no stale token (38-09 enforces that), so 0007 never changes the rules section.
- The SessionStart hook's detached commit stages exactly `changed_files`. Returning `.planning/STATE.md` and `CLAUDE.md` accurately is what keeps that commit scoped.
- `hooks/upgrade-project.test.js` case 15 and the adopt tests assert pending/applied lists on their own fixtures. Run them. If one now lists 0007, the fixture contains a stale token; fix the expectation only if the fixture's content really is stale.
</gotchas>

- Rewriting ROADMAP.md, PROJECT.md, SUMMARY/VERIFICATION/TRD/OBJECTIVE/CONTEXT files, milestones or todos (they are historical, and out of the allowlist).
- Rewriting Session Log history.
- Mapping `/devflow:update` to anything.
</anti_patterns>
