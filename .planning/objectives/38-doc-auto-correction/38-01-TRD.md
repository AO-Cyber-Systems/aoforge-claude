# TRD 38-01: `lib/doc-refs.cjs` — the command-reference resolver

<objective>
Build the single resolver every later TRD uses to find and fix stale command references. It is keyed
off the existing `DEPRECATION_MAP`, extended with the `/df:` prefix rule and the two commands that
were removed with no replacement. This is the only place command-rename logic lives.

fixture_strategy=generators. Constraints honored: `no_llm_test_data` (hand-written strings only),
`no_property_based_default`, `no_gherkin_layer`.

## Test list

`doc-refs.test.cjs` (copy into its header comment):
1. `resolveToken('df','plan-objective')` → `{kind:'prefix', replacement:'/devflow:plan-objective'}`.
2. `resolveToken('df','health')` → `{kind:'renamed', replacement:'/devflow:status check'}`; `('devflow','health')` → the same.
3. `resolveToken('devflow','add-objective')` → renamed `/devflow:objective add`; `('devflow','check-todos')` → `/devflow:todo list`; `('devflow','progress')` → `/devflow:status`.
4. `resolveToken('devflow','update')` and `('df','reapply-patches')` → `{kind:'removed', replacement:null}`.
5. `resolveToken('devflow','status', {liveSkills:new Set(['status'])})` → ok; `('devflow','nope', {liveSkills})` → unknown; without `liveSkills` → ok.
6. `scanText` on the three prose lines `progress: Present status to user`, `Update progress bar`, `status: in_progress` → `[]`.
7. `scanText('see /devflow:progress-bar')` with no liveSkills → `[]` (full-token match, not a prefix of `progress`).
8. `scanText` reports line/col (1-based) for `x /df:health` on line 3.
9. Ignore region: tokens between `<!-- doc-refs:ignore-start -->` and `<!-- doc-refs:ignore-end -->` are not reported; an ignore-start with no end → throws `DocRefsError`.
10. `rewriteText('Run /df:health --repair')` → text `Run /devflow:status check --repair`, one change `{from:'/df:health', to:'/devflow:status check', line:1}`.
11. `rewriteText` leaves `/devflow:update` untouched and lists it under `removed`.
12. `rewriteText` preserves CRLF and everything around the token (`"a\r\n/df:quick\r\n"` → `"a\r\n/devflow:quick\r\n"`).
13. Idempotence: for a hand-written 6-line sample mixing all kinds, a second `rewriteText` pass has zero changes.
14. `liveSkillNames(tmp)` where tmp has `a/SKILL.md`, `b/SKILL.md` and `c/` (no SKILL.md) → `Set{a,b}`.
15. `walkFiles(tmp, {include:['**/*.md'], exclude:['**/*.test.js', 'x/**']})` returns sorted posix relative paths and honours both lists (hand-built 5-file tree).
16. Guard: `doc-refs.cjs` source declares no string literal equal to any DEPRECATION_MAP value (it imports, never re-declares). Assert by reading the file and checking none of `'status check'`, `'todo list'`, `'objective add'` appear as literals.

`skill-route.test.cjs` (append):
17. `REMOVED_COMMANDS` deep-equals `['update','reapply-patches']` and shares no key with `DEPRECATION_MAP`.

<anti_patterns>
- Re-declaring any mapping in doc-refs.cjs (this makes a fifth copy, which is exactly what the objective removes).
- Bare-word matching (`progress`, `health`): false positives in `templates/state.md` and `templates/continue-here.md`.
- Using `String.split('\n').join('\n')` for rewrites: this loses CRLF. Rebuild the string by slicing at match offsets.
</anti_patterns>
