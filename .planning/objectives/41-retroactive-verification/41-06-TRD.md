- Use df-tools where a command exists (`roadmap update-job-progress 41`, `state record-session`); the `**Verified:**` lines have no df-tools command, so a targeted `Edit` per section is allowed.
- Commit via `node plugins/devflow/devflow/bin/df-tools.cjs commit "<msg>" --files <paths>`, never raw `git commit`.
- No version bump, tag, push or deploy. NEVER use port 8080. `rg -n -e` / `rg -nP`, never `rg -nE`. One plain command per Bash call.
- Do not plan or write gap-fix TRDs — list gaps only.
