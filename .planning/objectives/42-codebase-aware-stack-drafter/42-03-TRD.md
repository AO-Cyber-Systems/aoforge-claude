# TRD 42-03: Structured CI parsing, shell normalisation and semantic classification

<objective>
Replace the line-at-a-time CI scraping with three new pure modules:
- `stack-shell.cjs` turns shell text into logical invocations.
- `stack-ci.cjs` reads GitHub Actions workflows structurally: job, step, cwd, `uses:`.
- `stack-classify.cjs` is a data table that maps an invocation to a STACK.md key by tool semantics, not English tokens.

Nothing here is wired into `stack init` yet. That is 42-07. `stack-evidence.cjs` is not touched in this TRD.

Purpose: SDR-02. Every fleet dry-run defect was a line-classifier defect: dangling `\`, flag fragments,
comments as `test`, `echo` as `build`, `test -f x || {` as `test`, `helm lint` as `lint`, playwright as `test`.
Output: three modules, three test files, and one fixture module.
</objective>

<anti_patterns>
- Splitting on `|`. Pipes are part of one invocation. Only `&&`, `;` and newline split, at top level
  outside single/double quotes and `$( )`.
- Treating `uses:` steps as absent. Record them with `uses` set and no invocations. The report
  (42-08) uses them.
- Letting a hint (a job or step name) outrank the tool. The hint is a tiebreaker only when the tool is
  opaque (`./scripts/x.sh`, `bash scripts/x.sh`).
- A `-` / `--` / `$` leading token after the join means a fragment. Drop it, never classify it.
- Using `\btests?\b`: `test -f x` and `# run the tests` are exactly the failures.
</anti_patterns>

<error_recovery>
- Line continuation: a line ending in an odd number of trailing backslashes continues. `\\` at the end
  does not.
- Heredocs inside `run:` (`cat <<EOF`): skip every line until the terminator. Record nothing.
- Unknown YAML shapes (anchors, flow maps) must be skipped, never thrown on. `parseWorkflows` returns
  whatever it could read.
</error_recovery>

## Test list

Outermost to innermost (the CI parser, then normaliser, then classifier).

**stack-ci (parseWorkflows over fixture repos)**
1. Continuation shape: the `gosec … \` + `-fmt sarif ./...` block gives ONE invocation `gosec -exclude=G304 -fmt sarif ./...`. No invocation starts with `-`.
2. Flag-fragment shape: `flutter build ipa \` + `--build-number="${{ inputs.buildNumber }}"` gives ONE invocation starting `flutter build ipa`. No invocation is only a flag or only `${{ }}`.
3. Comment shape: a step whose block starts with `# run the tests` then `go test ./...` gives only `go test ./...`.
4. Echo shape: `echo "Published ..."` gives zero invocations. A step with `echo x` plus `make build` gives only `make build`.
5. Control-fragment shape: `test -f svc/go.mod || {` / `  echo missing; exit 1` / `}` gives zero invocations.
6. Working directory: workflow-level `defaults.run.working-directory: svc` applies to every step. Job-level overrides workflow-level. Step-level `working-directory` overrides both.
7. `uses: golangci/golangci-lint-action@v6` gives a step with `uses` set and `invocations: []`.
8. Quoted pipe: `sed -i 's|a|b|' f && go test ./...` gives two invocations, and the sed one is intact.
9. `continue-on-error: true` and a workflow `on: schedule:` are recorded on the step / workflow.
10. Multiple workflow files are read in sorted order. `.yaml` and `.yml` both count. A malformed file yields what was parseable and never throws.

**stack-shell (normalizeScript)**
11. Joins `\` continuations. `\\` at EOL is not a continuation.
12. Drop rules, table-driven: comment, blank, `echo`, `printf`, `test -f`, `[ -d x ]`, `if`, `then`, `fi`, `else`, `do`, `done`, `{`, `}`, `set -euo pipefail`, `export X=1`, `cd x`, `mkdir -p x`, `chmod +x x`, `git config ...`, `curl ...`, `gh ...`, `docker login ...`, `doctl ...`, a bare `--flag`, `${{ x }}`-only.
13. Prefix stripping: `HOME=/root ginkgo -r -p` gives tool `ginkgo`, and `env` holds HOME. `cd svc && go vet ./...` gives `go vet ./...` with cwd `svc`. `sudo`/`time` are stripped.
14. Heredoc bodies are skipped.

**stack-classify**
15. Table-driven: every row of the research table gives the expected `{key, form}`. Pin sast explicitly: `gosec ./...`, `gosec -exclude=G304 -fmt sarif ./...` (the joined continuation), `semgrep scan` and `codeql database analyze` all give `key: 'sast'` (NOT `audit`, NOT `format`). `govulncheck ./...` gives `audit`. The sast→audit collapse is 42-07's job, not the classifier's.
16. Negative: `test -f x`, `echo test`, `# tests` and `npx playwright test` must not classify as `test`. `helm lint chart/` must not classify as `lint`. `-fmt sarif ./...` gives null.
17. `classifyUses('golangci/golangci-lint-action@v6')` gives `lint`. `actions/setup-go@v5` gives null (setup).
18. Weak markers: `flutter analyze --no-fatal-infos` gives `{key: 'lint', weak: ['--no-fatal-infos']}`. Bare `gofmt -l .` gives `{key: 'format', form: 'check', weak: ['never-fails']}`.
19. Opaque wrapper `./scripts/check-vuln.sh` with hint `govulncheck` gives `audit` with `confidence: 'low'`. The same wrapper with no hint gives null.
