# TRD 72-14: The final `devflow@aocyber` release: a pointer to AOForge

<objective>
Users who already have `devflow@aocyber` get their next update from the same marketplace. Ship them a final pointer
release: a SessionStart notice that says DevFlow is now AOForge and how to install it, and a forwarding skill for every
command so `/devflow:<name>` still lands on `/aoforge:<name>`. It must never gate anything, and it goes quiet once
AOForge's runtime is present. It is dropped in the release after 3.0.0.

Purpose: INST-05's pointer release and the devflow side of the coexistence guard.
Output: `plugins/devflow/` pointer plugin, its generator and tests, marketplace entry.
</objective>
