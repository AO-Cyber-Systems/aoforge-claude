## Runtime model (binding, from OBJECTIVE.md)

- Library functions take `userHome` as a parameter. CLI entry points (`cmdProjectState`,
  `cmdInitNewProject`, `cmdInitSecurityAudit`, `cmdDetectBrownfieldMap`) pass `os.homedir()`.
  In-process tests pass an mkdtemp fake home; CLI tests set `HOME` to it. Never the real `~/.claude`.
- CommonJS, sync fs, no new dependencies.

  languages. `detectMarkers` in stack-profile.cjs names none (35-02's C14 keeps running).

## Marker additions (locked)

- project-state.cjs `MANIFEST_LANG` — APPEND: `['pubspec.yaml','dart']`, `['build.gradle.kts','kotlin']`, `['settings.gradle.kts','kotlin']`, `['build.gradle','java']`, `['Package.swift','swift']`.
- project-state.cjs `EXTS` and brownfield-detector.cjs `EXTS` — add `.dart`, `.kt`, `.kts`, `.swift` (identical sets; keep the "must not diverge" comment true).
- init.cjs `cmdInitNewProject` (:599-614): `find` gains `-o -name "*.dart" -o -name "*.kt"`; `hasPackageFile` gains `pubspec.yaml`, `build.gradle`, `build.gradle.kts`, plus any detectMarkers marker present at root.
- init.cjs `cmdInitSecurityAudit` (:1018-1026) — the second detector copy (the approved plan's ":10-21" reference was stale; this is the actual second site): push `dart` for `pubspec.yaml`, `kotlin` for `build.gradle.kts`, `swift` for `Package.swift`, and each matching org profile's `languages` (deduped).

```js
// stack-profile.cjs
detectMarkers({ userHome = null } = {}) →
  listOrgProfiles({ userHome }).flatMap(p => (p.detect || []).map(marker => ({ marker, profile: p.id, languages: p.languages || [] })))
matchMarkersAt(root, markers) → markers present at root (literal filename, or `*.ext` against root entries)
```
project-state `detectManifest(rootDir, { userHome } = {})`: built-ins first (unchanged order + appended),
then org markers → `primary_lang = languages[0] || profile`. `getProjectState(cwd, { now, userHome })` threads it; `cmdProjectState` passes `os.homedir()`.
brownfield: `countSourceFiles(root, { extraExts })`; `cmdDetectBrownfieldMap` adds `.ext` from `*.ext` markers.
