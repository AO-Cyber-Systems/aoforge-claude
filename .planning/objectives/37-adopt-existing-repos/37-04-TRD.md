# TRD 37-04: The three heuristics delegate to repo-state

<objective>
Make the three existing heuristics thin adapters over 37-01's detector so there is exactly one
definition of "what kind of repo is this". Public outputs stay the same (plus one additive field
each), existing tests stay green, and a parity test proves the adapters agree on real fixtures.

Resolved intent: kind=plugin, work=feature, tdd=strict, test_list_first=required,
fixture_strategy=generators (37-01's `adopt-fixtures.cjs`, import only). Constraints honored:
`no_llm_test_data`, `no_property_based_default`, `no_gherkin_layer`.
</objective>

  failure → STOP and report; never bypass. One plain command per Bash call. Never port 8080. No
  version bump, tag or push.
- Commits: `test(37-04): ...` → `feat(37-04): ...` / `refactor(37-04): ...`.

const repoState = require('./repo-state.cjs');
const { detectManifest, gitAgeDays, countSourceFiles } = repoState;   // moved there
function isScratchDir(absPath) { return repoState.isScratchDir(absPath, { userHome: os.homedir() }); }
function getProjectState(cwd, { now = new Date().toISOString(), userHome = null } = {}) {
  const root = path.resolve(cwd);
  const { state, signals, derived } = repoState.detectRepoState(root, { userHome });

}
