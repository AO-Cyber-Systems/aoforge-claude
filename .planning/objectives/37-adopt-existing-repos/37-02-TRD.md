# TRD 37-02: Global `--cwd <dir>` for df-tools

<objective>
df-tools always uses `process.cwd()` (`df-tools.cjs:270`), so a skill cannot point it at `[path]`.
Add one global flag, parsed once before dispatch, that `chdir`s into the target. Every subcommand
then gets it for free, including `commit`, `validate health`, `stack` and the new `adopt`.

Resolved intent: kind=plugin, work=feature, tdd=strict, test_list_first=required,
fixture_strategy=generators. Constraints honored: `no_llm_test_data`, `no_property_based_default`,
`no_gherkin_layer`.
</objective>

## Runtime model (binding, from OBJECTIVE.md)

- CommonJS `.cjs`, synchronous fs, **no new npm dependencies**.
- Tests spawn df-tools with `env: {...process.env, HOME: <fake home>}` and a mkdtemp cwd. **Nothing
  may read or write the real `~/.claude`.** Fixture repos come from 37-01's `adopt-fixtures.cjs`

- Commits via `node ~/.claude/devflow/bin/df-tools.cjs commit "<msg>" --files <paths>`; signing
  failure → STOP and report; never bypass. One plain command per Bash call. Never port 8080. No
  version bump, tag or push.
- Commits: `test(37-02): ...` → `feat(37-02): ...`.

16. `['--cwd=']` / `['--cwd']` → error `--cwd requires a directory`.

Dispatcher entry (`df-tools.cjs:263-300`, verified 2026-09-27):

```js
async function main() {
  const args = process.argv.slice(2);
  const rawIndex = args.indexOf('--raw');
  const raw = rawIndex !== -1;
  if (rawIndex !== -1) args.splice(rawIndex, 1);

  const command = args[0];
  const cwd = process.cwd();
  // ── `--help` is a question ... ─ hasTopLevelHelpFlag(args) && !ownsHelp(args) → printHelp
  if (!command) { process.stderr.write(topLevelUsage()); process.exit(1); }
  switch (command) { ... }
```

Insert, right after the `--raw` splice and BEFORE `const command = args[0]`:

```js
  const cwdFlag = extractCwdFlag(args, { originalCwd: process.cwd() });
  if (cwdFlag.error) { process.stderr.write(`Error: ${cwdFlag.error}\n`); process.exit(1); }
  if (cwdFlag.dir) process.chdir(cwdFlag.dir);
  args.splice(0, args.length, ...cwdFlag.args);
```

Flag-region boundary: `help.cjs` `helpScanLimit(args)` :424 (FREEFORM_TAIL `handoff create`, literal
`--`). It is not exported today; export it (additive) and reuse it — one definition of "the part of
argv df-tools reads". For a LEADING `--cwd` (args[0]), strip it first, then compute the limit on the
remaining args.

Commands that own `--cwd`: `dup-detect-cli.cjs:109,204` (`else if (t === '--cwd') out.cwd = ...`).
`OWN_CWD = new Set(['dup-detect'])`; a leading `--cwd` still applies to them (it precedes the
command), a trailing one is left for them.

help.cjs `topLevelUsage()` :441 first line → `'Usage: df-tools [--cwd <dir>] <command> [args] [--raw]'`
and add one line under it: `'  --cwd <dir>  run as if started in <dir> (resolved against the current directory)'`.
</codebase_examples>

<gotchas>
- `--raw` is stripped anywhere in argv today (even in a forwarded tail). Do not "fix" that here;
  only `--cwd` gets the boundary rule.
- `process.chdir` must happen before `const cwd = process.cwd()` and before any `require` that
  captures cwd at load time. The top-of-file requires in df-tools.cjs do not read cwd; keep it so.
- The help tests (`help.test.cjs:36-60`) parse `case '...'` lines with a 4-space indent; this TRD
  adds no case, so they must pass unchanged. Check test 139 (bare `--help`) for any assertion on the
  exact first usage line and update only if it asserts the old string verbatim.
- On macOS a mkdtemp path realpaths `/var` → `/private/var`; compare `find-objective` results with
  `fs.realpathSync` on both sides.
</gotchas>

<anti_patterns>
- Per-subcommand `--cwd` parsing (the point is one global flag).
- Consuming `--cwd` inside `handoff create`'s tail (it belongs to the forwarded command).
- Silently ignoring a bad `--cwd` and running in the original directory.
</anti_patterns>

<error_recovery>
- A spawned test writes into this repo → the chdir did not happen before dispatch; stop, `git status`,
  restore only the files the test wrote, fix the ordering.
</error_recovery>
