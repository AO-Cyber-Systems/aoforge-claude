`no_llm_test_data`, `no_property_based_default`, `no_gherkin_layer`.

invocation (CLAUDE.md, `30-agent-environment-hygiene/SUMMARY.md:55`, and five site pages) is

documented form. Gate names stay exactly `edits|commits|changelog`: do NOT expand `GATES` (research
pitfall 8). The site pages that say `--gate gate-edits` are corrected in 39-03, not aliased here.

```js
case 'override': {
  // df-tools override --gate <g> --reason <why> | --list [--limit N] — TRD 30-04 module, wired in TRD 39-02
  const { output: outputAudit } = require('./lib/helpers.cjs');
  const { runOverride } = require('./lib/audit-cli.cjs');

  if (!r.ok) error(r.message);

}
```
