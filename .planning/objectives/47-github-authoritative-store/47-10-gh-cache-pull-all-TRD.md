# TRD 47-10: Cache rebuild — `gh pull --all`, generated ROADMAP/STATE (GST-07)

<objective>
Create `lib/gh-cache.cjs` and add `--all` to `gh pull`: read the whole planning hierarchy from GitHub (issues, comments, wiki or
`docs/devflow/` pages) into a model, materialise it into the canonical `.planning/` layout, and write only what changed —
never deleting, never clobbering local edits or hand-maintained files. Render ROADMAP and STATE views from the issues with one
renderer that the wiki `Roadmap` page also uses.

per-objective drift pull is unchanged).

## Decisions taken in planning

- **D-25 Round-trip scope (research Open Q8).** OBJECTIVE.md, `<NN>-CONTEXT.md` and `<NN>-RESEARCH.md` are stored verbatim as wiki pages and are
  part of the SC1 byte comparison, as are TRD files, SUMMARY files, VERIFICATION, PROJECT.md, REQUIREMENTS.md and `codebase/*.md`. The objective
  ISSUE body is a summary view and is not materialised as a file. ROADMAP.md and STATE.md are generated views: excluded from the byte compare,
  covered instead by "second pull writes zero files" and renderer tests.
- **D-26 Overwrite rules.** For each target path: absent → write; bytes equal → skip; differs and local hash equals the cache-index hash from the
  last sync → write (GitHub wins, the local copy was untouched); differs otherwise → `local_modified` (skip, report; `--force` writes).
  ROADMAP.md/STATE.md: write only if absent or already starting with `GENERATED_HEADER`; otherwise report `hand_maintained` and skip — this repo's
  own hand-written STATE.md/ROADMAP.md are therefore never clobbered before objective 51 migrates them.
- **Cache index** lives in the outbox state dir (`gh-outbox.readCacheIndex/writeCacheIndex`, key = path relative to `.planning/`, value contentHash).
  `recordCacheBaseline(root, relPaths)` records the current local hashes; 47-12 calls it after a successful push flush.
- **Objective ↔ TRD association** is by marker id prefix (`7-01` belongs to objective `7`); native sub-issue links are read for the orphan report only,
  so task-list hosts pull identically.
- **Exit codes for `gh pull --all`:** 0 ok; 1 error; 2 ok but `local_modified`/`hand_maintained`/orphans need a human look (same "needs a human"
  meaning as the outbox's 2).
- **Base refresh.** After pull, `gh-outbox.setBase` for each pulled issue/comment target unless the journal has a pending op for that target.
- **Path safety.** A `devflow:file` / `devflow:dir` value containing `/`, `..` or not starting with the owning id's prefix is rejected and reported;
  nothing is written outside `.planning/`.

<anti_patterns>
- `gh issue list --search` or reading only the first comments page (46 defect 8).
- Rewriting identical files (cache churn → the watcher attaches them to tool results).
- Deleting local files that GitHub lacks; resetting a wiki clone that has unpushed commits.
- Two roadmap renderers (one for the wiki page, one for the file).
</anti_patterns>

<error_recovery>
- Wiki `uninitialised`/`unavailable` → pages section skipped with a report line; issue-derived files still materialise; exit 2.
- An objective issue without a `devflow:dir` marker → listed under `no_dir` (it was never pushed by 47); its TRDs are skipped.
</error_recovery>

Remote model (fake + wiki fixture)

6. Docs mode (`ownerType:'User', hasWiki:false`, pages under `docs/devflow/`) → same model.
7. Objective without dir marker → `no_dir`; a TRD issue whose objective prefix matches no objective → orphan.

Writing rules
8. Empty cache → every file written; a second `pullAll` → zero writes (assert via mtimes and the returned `written` list).
9. Local file edited after a recorded baseline, GitHub unchanged → bytes differ, local hash ≠ index → `local_modified`, not overwritten; `--force` overwrites.
10. Local file untouched since baseline, GitHub changed → overwritten (GitHub wins).
11. Hand-written ROADMAP.md/STATE.md (no header) → `hand_maintained`, untouched; absent → generated written.
12. Local file absent on GitHub → listed in `orphans`, still on disk.
13. Base refresh: pulled issues get `setBase`; an issue with a pending journal op keeps its old base.

Command
14. `cmdGhPull(root, ['--all'], true)` → JSON `{ok:true, written:[...], skipped, local_modified, orphans}` exit 0; with a `local_modified` → exit 2; `github.enabled:false` → skipped, zero gh calls.
15. `cmdGhPull(root, ['7'])` (existing per-objective path) behaves exactly as before (existing tests green).
