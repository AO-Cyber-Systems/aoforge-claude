# TRD 36-05: The SessionStart upgrade hook, the detached commit, and one-shot notices

<objective>
Make a behind project upgrade itself when a session starts:

1. **Fast path.** If the stamp equals the bundled plugin version, exit. This is the common case and
   costs one small JSON read.
2. **Apply.** Otherwise, synchronously apply the `auto` migrations using the bundled code.
3. **Commit.** Spawn a detached child that commits exactly `changed_files` via the bundled
   `df-tools commit --files`, unless a skip rule holds.
4. **Notices.** Record the result, pending confirm migrations and skip reasons in
   `.planning/.devflow-notices.json`. `route-results.js` emits them once on the next prompt.

Resolved intent: kind=plugin, work=feature, tdd=strict, test_list_first=required,
fixture_strategy=generators (36-01 `makeV1Project`, `makeStampedProject`, `initGitFixture`, `gitEnv`,
`makeFakeHome`, `snapshot`; read-only). Constraints: `no_llm_test_data`, `no_property_based_default`,
`no_gherkin_layer`.
</objective>

## Runtime model (binding, from OBJECTIVE.md)

- **Fake HOME for every spawned hook** (`env: gitEnv(fakeHome)` plus `CLAUDE_PLUGIN_ROOT=<repo>/plugins/devflow`).
  Nothing reads or writes the real `~/.claude`. The plugin root is only READ.
- **Git fixtures:** `initGitFixture` sets `commit.gpgsign=false` on the fixture repo only. The
  signing-failure case sets `commit.gpgsign=true`, `gpg.format=openpgp` and `gpg.program=<tmp>/fail-sign.sh`
  (`#!/bin/sh\nexit 1`) on that fixture only. Never on this repo, never `--global`.
- **Never bypass signing** in code: the child never passes `--no-gpg-sign`, `-c commit.gpgsign=false`, or
  `DEVFLOW_ALLOW_RAW_COMMIT`. It calls `df-tools commit` and reports what happened.
- CommonJS, sync fs in the hook, no new deps. Never throws, never blocks the session (exit 0 always).
- Commits of this TRD via `node ~/.claude/devflow/bin/df-tools.cjs commit … --files`; 1Password
  failure → STOP and report. One plain command per Bash call. Never port 8080.
- Commits: `test(36-05): ...` → `feat(36-05): ...`.

<codebase_examples>
Hook flow (pseudocode):

```js
#!/usr/bin/env node
'use strict';
// SessionStart: upgrade a behind DevFlow project in place (objective 36). Never throws, always exit 0.
const pluginRoot = process.env.CLAUDE_PLUGIN_ROOT || path.resolve(__dirname, '..');
if (process.argv[2] === '--commit-child') return commitChild(process.argv.slice(3));
main();

function main() {
  if (process.env.DEVFLOW_SKIP_UPGRADE === '1') return;
  const root = findProjectRoot(process.cwd());           // nearest ancestor with a .planning/ DIR
  if (!root) return;
  const to = readJson(path.join(pluginRoot, '.claude-plugin', 'plugin.json'))?.version;
  if (!to) return;
  const stamp = readJson(path.join(root, '.planning', 'config.json'))?.devflow?.version;
  if (stamp === to) return;                               // FAST PATH — nothing else required
  const home = os.homedir();
  const lock = acquireLock(home, root); if (!lock) return;
  try {
    const git = gitState(root);                           // {isRepo, busy, detached, dirty:Set}
    const upgrade = require(path.join(pluginRoot, 'devflow', 'bin', 'lib', 'upgrade.cjs'));
    const notices = require(path.join(pluginRoot, 'devflow', 'bin', 'lib', 'notices.cjs'));
    const report = upgrade.apply({ projectRoot: root, userHome: home, pluginVersion: to });
    // notices: pending_confirm -> action; failed -> warn
    if (!report.changed_files.length) return;
    const skip = skipReason(git, report.changed_files);   // busy | detached | dirty-before | not a repo
    if (skip) { notice(warn, `DevFlow upgraded this project to v${to}; not committed: ${skip}. Changes are applied and uncommitted: …`); return; }
    ensureExcluded(root);                                  // .git/info/exclude
    spawn(process.execPath, [__filename, '--commit-child', root, to, ...report.changed_files],
          { cwd: root, detached: true, stdio: 'ignore', env: process.env }).unref();
  } catch (e) { /* warn notice if possible */ } finally { releaseLock(lock); }
}

function commitChild([root, to, ...files]) {
  const keep = files.filter(f => fs.existsSync(path.join(root, f)) || isTracked(root, f));
  const r = spawnSync(process.execPath, [path.join(pluginRoot, 'devflow', 'bin', 'df-tools.cjs'),
        'commit', `chore(devflow): upgrade project to v${to}`, '--files', ...keep],
        { cwd: root, encoding: 'utf-8', timeout: 120000 });
  // parse the JSON from stdout; committed → info notice "committed <hash>";
  // otherwise → warn notice "not committed: <reason | first stderr line | timeout>. Changes are applied."
}
```

Busy detection: for each of `rebase-merge`, `rebase-apply`, `MERGE_HEAD`, `CHERRY_PICK_HEAD`,
`REVERT_HEAD`, `BISECT_LOG`, check `fs.existsSync(<git rev-parse --git-path X>)`. Detached:
`git symbolic-ref -q HEAD` exits non-zero. Use `execFileSync('git', ['-C', root, …])`, never a shell string.

`cmdCommit` facts (lib/misc.cjs:433): returns `{committed:false, reason:'skipped_commit_docs_false'}`
when `commit_docs` is false and `skipped_gitignored` when `.planning` is ignored. It refuses during
a merge (`merge_in_progress`, exit 1). On success it prints `{committed:true, hash}`. All of these
land in the child's notice.

<gotchas>
- **Poll, don't sleep blindly**, for the detached commit: loop `git rev-list --count HEAD` every
  200 ms up to 20 s. For "no commit" cases, wait for the notice file to show the skip (it is written
  synchronously before exit), then confirm the count is unchanged.
- Renamed JOB files: an untracked, now-missing old path makes `git commit -- <path>` fail. That is
  why `commitChild` filters to paths that exist or are tracked (`git ls-files --error-unmatch`).
- Realpath the project root before hashing the lock name (same rule as 36-01's backup dir).
- Lock: `fs.openSync(lockPath, 'wx')`; on EEXIST, if `mtime` is older than 120 s, unlink and retry
  once; else return null. Always release in `finally`.
- The child inherits `process.env`, so a spawned test's fake HOME applies to its git and df-tools.
- The hook's stdout must stay empty. SessionStart stdout becomes context; notices go through
  route-results.
- `.gitignore` in THIS repo: add `.planning/.devflow-notices.json` next to `.planning/.skill-active` (:46).
- The fixture's `commit_docs` must be true (template default) or the commit is skipped by design;
  test 4 relies on the default.
</gotchas>

<anti_patterns>
- `require('~/.claude/devflow/...')` or any path under `os.homedir()` for code.
- Awaiting the child, or `stdio: 'inherit'`.
- `git add -A` / committing without `--files`.
- Any flag or env that disables signing in the child.
- Writing the notices file anywhere but `.planning/.devflow-notices.json` (project) or the global path.
</anti_patterns>

<error_recovery>
- A detached child is left running after a test → have tests `t.after` wait on the poll loop.
  The child exits by itself after its spawnSync returns (120 s timeout max).
- An existing route-results test changes → the handoff path must be byte-identical when there are no
  notices; diff renderResults output.
</error_recovery>
