<objective>

With 43-02's effect guard shipped to the runtime mirror, run the gates read-only and record the real results.

**User decision D10 (binding, 2026-10-02):** record real `stack verify --run` results in `.planning/objectives/43-stack-drafter-rules/43-ROLLOUT.md` ONLY. ## Binding rules

- **Read-only towards every other repo.** The only file this TRD writes is 43-ROLLOUT.md, via `node plugins/devflow/devflow/bin/df-tools.cjs doc put objectives/43-stack-drafter-rules/43-ROLLOUT.md --from <file>`. Never pass `--write` to `stack init`/`stack report`. Never `git add`/`commit`/`checkout`/`stash` in a fleet repo.
- Never port 8080, in any command or `--include test` run. RUN_POLICY denies it, so keep it that way. Never run deploy, push or `e2e_env` keys. `--include` defaults to none (the default keys format/lint/typecheck/build only). `test`/`e2e` only for repos the human opts in at the checkpoint.
- Per repo, around each run, take the harness's own porcelain + hash snapshot (redundant with the D8 guard, on purpose). If a delta survives, STOP the rollout, report the paths, and do not restore by hand. Ask the human.
- One plain command per Bash call (one repo per call). Long runs use the `--timeout` flag (default 300s per gate).
- Mirror sync touches `~/.claude/devflow/` only. Run it with `DEVFLOW_SKIP_GLOBAL_UPGRADE=1`, so `~/.claude/CLAUDE.md` and skills are untouched.

<anti_patterns>
- Running anything before the checkpoint is approved.
- Treating a non-zero gate exit as a rollout failure. Pre-existing gate-red is a RESULT to record, not something to fix here.
- Restoring fleet files by hand, or "cleaning up" pre-existing dirty state.
- Writing STACK-REPORT.md or STACK.md anywhere, or opening PRs.
</anti_patterns>

<error_recovery>
- Mirror sync fails or `cmp` differs: stop before the checkpoint and report it. The run plan cannot be trusted on a stale mirror.
- A repo is missing, or its path differs: mark the row `absent` and continue.
- A guard `run.mutated` with `restored: true`: record it and continue (the guard did its job). With `restored: false`, or a harness-level surviving delta: STOP and ask the human.
</error_recovery>
