## Rewrite recipe

| Old | New |
|---|---|
| Write PROJECT.md / REQUIREMENTS.md | draft → `doc put PROJECT.md|REQUIREMENTS.md --from "$DRAFT"` |
| Researchers/synthesizer write `.planning/research/<X>.md` | draft → `doc put research/<X>.md --from "$DRAFT"` (wiki `Research-<X>`, D-04) |
| Roadmapper writes ROADMAP.md / STATE.md | `planning mode` guard: local → as today (unchanged instruction next to the guard); store → `objective add "<desc>"` per objective (creates issue + dir), then `gh pull --all` regenerates ROADMAP/STATE |
| Create objective dirs/OBJECTIVE.md by hand | `objective add` / `objective insert`; content via `objective put <id> --from "$DRAFT"` |
| Append the MILESTONES.md entry | draft → `milestone put <version> --from "$DRAFT"` |
| Archive `milestones/vX.Y-ROADMAP.md`, `-REQUIREMENTS.md`, `-MILESTONE-AUDIT.md` | today's `milestone complete` (local) / `milestone complete <version>` + `doc put milestones/<version>-<KIND>.md` for each archive written from a draft (store) |
| remove-objective | `objective remove <id> --confirm`; add one line: "store mode refuses deletes; close it with `objective set-status <id> cancelled`" |
| verb line with `2>/dev/null` | drop the redirect |
