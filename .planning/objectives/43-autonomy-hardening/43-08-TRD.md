# TRD 43-08: Checkpoint-aware job index, and the CI guard against legacy agent-path reads

<objective>
Two follow-ons that must land after the prompt TRDs.

1. **The job index.** 43-01 makes executors write a `## Progress` checkpoint into SUMMARY.md
   early. `objective-job-index` treats ANY SUMMARY file as done, so a re-run of execute-objective
   would silently skip a half-finished TRD. The fix: a checkpoint-only SUMMARY is not complete.
   `task_count` also counts only `## Task N` headings, which the XML TRD format doesn't use, so
   it reads 0 for every modern TRD. Fix that too.
2. **The CI guard.** 43-01 and 43-02 removed every "read ~/.claude/agents/<name>.md"
   instruction. Add the doc-refs CI guard (AUT-03) so they can't come back.

This TRD depends on 43-06 only because both edit misc.cjs.
</objective>
