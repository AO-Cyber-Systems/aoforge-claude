# TRD 45-10: Autonomous hook markers leave `.planning/`, plus the SC1 audit

<objective>
Success criterion 1 says no DevFlow hook writes a file under a project's `.planning/` per call or
per session, except planning artifacts. Two hooks still do. `verify-commits.js` writes
`.planning/.autonomous-retry-<agent_id>` (SubagentStop, autonomous mode), and `verify-completion.js`
writes `.planning/.autonomous-resume-<objective>` (Stop, autonomous mode). No migration ignores
either file. This TRD moves both to `~/.claude/devflow/state/hook-markers/<repo-key>/`. It also adds
an audit test that fails whenever any hook writes a new dotfile into `.planning/`, so the next
offender is caught in CI rather than in a user's diff.
</objective>

## Test list

hook-marker-store.test.cjs:
1. `markerRoot({DEVFLOW_HOOK_MARKER_DIR: X})` returns X. `markerRoot({}, '/h')` returns `/h/.claude/devflow/state/hook-markers`.
2. `markerDir(root)` returns `<markerRoot>/<upgrade.repoKey(root)>` and is never inside root.
3. `markerFile(root, 'autonomous-retry-../../x')` is sanitized (no separator or dot-segment escape).
4. `cleanStale(dir, now, 1h, 'autonomous-retry-')` removes only matching files older than 1h. A missing dir returns 0 and doesn't throw.

verify-commits.test.js:
5. Autonomous + mid-execution + no recent commits: the first SubagentStop blocks and creates `<markerDir>/autonomous-retry-<agent>`. `.planning/` gains no file.
6. The second SubagentStop for the same agent is allowed (the marker already exists).
7. A stale marker (older than 1h) in the store dir is removed. An in-tree `.planning/.autonomous-retry-x` is left untouched and never consulted (a leftover for doctor).

verify-completion.test.js:
8. The resume counter increments in `<markerDir>/autonomous-resume-<objective>`, and `.planning/` gains no file.
9. Clearing removes the store file. A garbage counter reads as 0 (the existing semantics, via the store).

planning-writes.audit.test.js:
10. Behavioral: for each hook command in `hooks/hooks.json` plus plugin.json's statusLine, run it with a representative payload for its event against the autonomous fixture. Snapshot every dotfile under every `.planning/` in the fixture (path, size, mtimeMs, sha1) before and after, and assert that new or changed dotfiles are a subset of the allowlist. The failure message names the hook and the file.
11. Static: every `.planning`-relative dotfile literal in non-test `hooks/*.js` and `hooks/lib/*.js` appears in the ALLOWED_WRITES or READ_ONLY table. An unknown literal fails, naming the file and line.
12. The allowlist is exactly `{.skill-active, .edit-override, .devflow-notices.json}`. Changing it requires editing the test, so it stays a reviewed decision.
