<anti_patterns>
- Don't trust `.plugin-version` alone for mirror freshness. Compute the digest of the real mirror content with `digestTree(mirrorDir)`, since digestTree ignores the extra top-level entries.
- Never delete plugin cache dirs, because a running session may use them. The check is report-only by requirement.
- Don't hard-code a "latest model" table. Report ids structurally and compare mirror against installed.
- Don't run the real sync-runtime against the real HOME. The spawn env HOME is always ctx.userHome.
</anti_patterns>

<gotchas>
- The fix must also work when the installed sync-runtime predates the digest logic. Removing `.plugin-version` forces a mirror in every sync-runtime version ("mirror missing/unparseable → mirror"). Never remove it when mirror > installed, because that would downgrade.
- sync-runtime exits 0 even on failure. After the spawn, the fix re-reads `.plugin-version` plus the digest and reports `applied:false` with its stderr when they still don't match.
</gotchas>

## Test list

10-runtime-mirror.test.cjs (fixture: `makeInstalledPlugin` + `copyRealRuntimeFiles(installPath, ['hooks/sync-runtime.js', 'devflow/bin/lib/runtime-digest.cjs'])` + `makeMirror`):
1. Mirror 2.10.1, installed 2.11.0 → error, finding names both versions, fixable.
2. Same version, identical content → ok, and details carry both digests.
3. Same version, one mirror file differs → error "content drift", fixable.
4. Mirror 2.12.0 > installed 2.11.0 → warn "mirror ahead (dev checkout?)", not fixable.
5. No `installed_plugins.json` entry → warn, not fixable. No mirror dir → error, fixable when installed exists.
6. The fix on (1) spawns the real fixture sync-runtime with env `{CLAUDE_PLUGIN_ROOT: installPath, HOME: home, DEVFLOW_SKIP_GLOBAL_UPGRADE:'1'}`. Afterwards `.plugin-version` === installed and digestTree(mirror) === digestTree(installPath/devflow). A re-run gives ok. The fix result has `applied:true`, `changed:['~/.claude/devflow']`.
7. The fix on (3) (same version) also resolves it.
8. The fix never runs in case (4): `run().fixable` is false. Calling fix directly anyway returns `{applied:false, refused}` and leaves the mirror untouched.

11-12-install.test.cjs:
9. plugin-cache: cache dirs 2.7.1, 2.10.1, 2.11.0 with installed 2.11.0 → warn listing 2.7.1 and 2.10.1 with byte sizes, not fixable, and fix_command is a `rm -rf` line for each stale dir preceded by "after quitting sessions that use them". Only the installed dir → ok.
10. hooks-registry: the fixture hooks.json references `hooks/a.js` (present) and `hooks/b.js` (missing) → warn naming b.js. An unregistered `hooks/c.js` without DRAFT → warn. An unregistered `hooks/d.js` with a `DRAFT` header → ok. `hooks/x.test.js` and `hooks/lib/*.js` are ignored. A statusLine pointing to a missing file → warn.
11. hooks-registry on a copy of the REAL `plugins/devflow/hooks/` + `.claude-plugin/plugin.json` → ok (regression guard for the shipped plugin).

13-model-profiles.test.cjs:
12. The real bundled model-profiles.json → ok, with details `{models:{…}}`.
13. An agent tier referencing `'gpt'` (undefined key) → warn. A models value `'opus-latest'` (bad shape `^claude-[a-z]+-\d+(-\d+)*(\[1m\])?$`) → warn.
14. The mirror json ids differ from the installed json ids → warn "mirror model ids differ from installed plugin", listing both.
15. The file is missing or garbage in both locations → warn, not an error, and nothing throws.
