# TRD 44-07: `config-get` returns documented defaults for known-but-unset keys

<objective>
`config-get workflow.auto_advance` / `workflow.parallelization` exit 1 with `Key not found` when
the project's config.json predates the key (44-EVIDENCE DF-07). The workflows recover via
`|| echo`, but the agent sees an error on every run. A known key should answer with its
documented default. Unknown keys still error, so typos stay loud.
</objective>

<codebase_examples>
config.cjs `cmdConfigGet(cwd, keyPath, raw)` (~line 183):
- reads config.json and errors when it is missing;
- walks the dot path;
- any undefined value → `error(\`Key not found: ${keyPath}\`)`;
- else `output(current, raw, String(current))`.

templates/config.json leaves include:
- `mode`, `depth`
- `workflow.{research,job_check,verifier,auto_advance,verifier_checkpoints,decision_queue}`
- `planning.{commit_docs,search_gitignored}`
- `parallelization.{enabled,job_level,task_level,skip_checkpoints,max_concurrent_agents,min_jobs_for_parallel}`
- `gates.*` (incl. `editGate`)
- `safety.*`, `workstreams.*`, `github.*` (incl. `github.labels.*`)
- `awareness.*`, `daemon.*`

`workflow.parallelization` is NOT a template leaf, but agents ask for it (evidence DF-07). Its
documented meaning is `parallelization.enabled` (loadConfig's `parallelization` default true), so
it goes in ALIAS_DEFAULTS as a pointer to that leaf.
</codebase_examples>

<anti_patterns>
- Returning a default for ANY missing key. Typos must still fail.
- Hard-coding a second defaults table that can drift from templates/config.json. Derive from the
  template, with aliases as POINTERS (`'workflow.parallelization': 'parallelization.enabled'`),
  not literals.
- Treating an array/object leaf (e.g. `awareness.branch_patterns`) as unknown. Arrays are leaves
  too; output them like today's set-value path.
</anti_patterns>

<error_recovery>
- If the template can't be read (a broken install), fall back to today's behaviour (`Key not found`).
</error_recovery>

## Test list

Outermost (CLI) to innermost.

1. (CLI) Config `{"mode":"yolo"}`: `config-get workflow.auto_advance --raw` → stdout `true`, exit 0.
   `config-get workflow.parallelization --raw` → `true`. `config-get gates.editGate --raw` → `strict`.
   `config-get parallelization.max_concurrent_agents --raw` → `3`.
2. (CLI) Config `{"workflow":{"auto_advance":false}}`: `config-get workflow.auto_advance --raw` → `false` (the set value wins).
3. (CLI) `config-get workflow.nope` → exit 1, stderr contains `Key not found: workflow.nope`.
   `config-get totally.unknown.key` → exit 1.
4. (CLI) No config.json → today's `No config.json found` error, unchanged.
5. (CLI) JSON (non-raw) mode for a default returns the same JSON shape as for a set value.
6. (unit) `documentedDefault`:
   - `'workflow.auto_advance'` → `{known:true, value:true}`
   - `'workflow.parallelization'` → `{known:true, value:true}` (alias)
   - `'awareness.branch_patterns'` → known, array value
   - `'workflow'` (a non-leaf section) → known:false (sections aren't defaults)
   - `'nope'` → known:false
