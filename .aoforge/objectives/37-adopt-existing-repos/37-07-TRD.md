# TRD 37-07: `adopt scaffold` — the deterministic DevFlow scaffold, resumable

<objective>
After the LLM half has mapped the code and written PROJECT.md, `adopt scaffold` produces everything
else a DevFlow project needs, deterministically: STATE.md, an objective-less ROADMAP.md, STACK.md
from evidence, the CLAUDE.md managed block, config.json + state.json + version stamp (via the
objective-36 runner), and pruner registration. Re-running it after an interruption finishes the job
without duplicating anything.

Resolved intent: kind=plugin, work=feature, tdd=strict, test_list_first=required,
fixture_strategy=generators (`adopt-fixtures.cjs`: makeFixture, writeMappedDocs, writeProjectMd).
Constraints honored: `no_llm_test_data` (PROJECT.md and codebase docs are the factory's literal
stand-ins), `no_property_based_default`, `no_gherkin_layer`.
</objective>

## Runtime model (binding, from OBJECTIVE.md)

- CommonJS, synchronous fs, **no new npm dependencies**. YAML frontmatter via `yaml-lite.cjs` (or the
  existing `frontmatter.cjs` helpers) — no new parser.
- `userHome`, `pluginVersion`, `now` and git `env` are injected into adopt.cjs; only adopt-cli.cjs
  calls `os.homedir()`. Spawned tests set `HOME=<fake home>`. **Nothing may read or write the real
  `~/.claude`.**
- **Never touch any real user repository.** Fixtures under mkdtemp only.
- Commits via `node ~/.claude/devflow/bin/df-tools.cjs commit "<msg>" --files <paths>`; signing
  failure → STOP and report; never bypass. One plain command per Bash call. Never port 8080. No
  version bump, tag or push.
- Commits: `test(37-07): ...` → `feat(37-07): ...`.

<gotchas>
- `upgrade.apply` backs up `.planning/` before 0001/0003 write. That is expected; it is also what
  makes test 4's backup dir exist.
- If the STATE literal's `**Current Objective:** None` trips health W002 (a warning) that is still
  "no errors", but prefer a literal that yields no W002; check `validate.cjs` :250-265.
- Resume-state guard: call `preflight()` and require `route === 'resume'`; scaffold's own writes are
  all under owned paths so a partially scaffolded tree still resumes.
- The marker is updated last (after register), so an interruption leaves `scaffolded` false and the
  next run redoes only the missing pieces.
- Do not hard-code template version `2`; read it via loadClaudeMdTemplate.
</gotchas>

<anti_patterns>
- Inventing objectives, requirements or roadmap phases. ROADMAP has zero objectives by design.
- Overwriting any existing file (PROJECT.md, STATE.md, ROADMAP.md, STACK.md). Create-if-missing only.
- Re-implementing config.json or state.json shapes instead of letting 0001/0003 create them.
- Running `stack init --force`.
</anti_patterns>

<error_recovery>
- `validate health` shows an error on the fresh scaffold → fix the generated literal (STATE/ROADMAP)
  or the order of steps, not the validator. Record the error code and fix in SUMMARY.
- `stack validate` fails on a fixture → inspect `initProfile(...).validation.errors`; if the
  fixture lacks evidence the bundled `general` profile requires, fix the FIXTURE expectation only if
  37-01's factory is wrong — do not edit adopt-fixtures.cjs here; instead report it and stop.
</error_recovery>

daemon/PID tests fail in any git worktree). So this gate compares failing test **names** against
`.planning/objectives/37-adopt-existing-repos/baseline-failures.tsv` (21 lines, `file:line<TAB>name`),
not counts.

   `node --test --test-reporter=spec 'plugins/devflow/**/!(micro).test.cjs' 'plugins/devflow/**/*.test.js' 'scripts/**/*.test.cjs'`
   and write the output to a file in your session scratchpad (never the repo).
2. Extract failing names from the closing `✖ failing tests:` section: each entry gives
   `test at <file>:<line>:<col>` then `✖ <name> (<ms>)`; strip the duration.
3. A failure whose name is in the TSV's second column is **pre-existing**.
4. Any other failure is a candidate regression. Re-run just its file with `node --test <file>`.

   - Still fails and this TRD's diff (`git diff --stat <wave base>`) touched code it exercises →
     **regression, blocks**. Fix it before completing.

     name, re-run output and why it's unrelated. Don't block.
5. **Never edit `baseline-failures.tsv`** to pass the gate. Tests added by this objective are not in
   the TSV and must pass.
