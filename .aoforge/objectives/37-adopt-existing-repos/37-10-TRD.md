## Runtime model (binding, from OBJECTIVE.md)

- CommonJS, synchronous fs, **no new npm dependencies**. Hooks keep their contract: never throw,
  exit 0, only the documented stdout.
- Spawned hook tests use mkdtemp cwds and `HOME=<fake home>`. **Nothing may read or write the real
  `~/.claude`.** **Never touch any real user repository.**
- Commits via `node ~/.claude/devflow/bin/df-tools.cjs commit "<msg>" --files <paths>`; signing
  failure → STOP and report; never bypass. One plain command per Bash call. Never port 8080. No
  version bump, tag or push.
- Commits: `test(37-10): ...` → `feat(37-10): ...`.

  and scratch dirs are never substantive), so in practice the init-offer always names adopt; the
  `repoState` guard only keeps the old text for callers that do not pass it.
- Bumping the global template version makes every existing managed `~/.claude/CLAUDE.md` block
  stale; objective 36's global upgrade refreshes it on the next sync. This TRD never runs the global
  upgrade against the real home.
- route-intent tests may snapshot the rendered DevFlow box; the new entry only matters when the
  prompt matches it.
