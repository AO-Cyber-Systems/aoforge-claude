## Runtime model (binding, from OBJECTIVE.md)

- CommonJS, synchronous fs, **no new npm dependencies**.
- Every spawned hook/CLI test sets `HOME=<fake home>` (from `makeFakeHome()`), and the hook tests set
  `CLAUDE_PLUGIN_ROOT` to this checkout's `plugins/devflow` exactly as the existing
  upgrade-project.test.js cases do. **Nothing may read or write the real `~/.claude`.**
- **Never touch any real user repository.** Project dirs are mkdtemp / adopt-fixtures only.
- Commits via `node ~/.claude/devflow/bin/df-tools.cjs commit "<msg>" --files <paths>`; signing
  failure → STOP and report; never bypass. One plain command per Bash call. Never port 8080. No
  version bump, tag or push.
- Commits: `test(37-06): ...` → `feat(37-06): ...`.
