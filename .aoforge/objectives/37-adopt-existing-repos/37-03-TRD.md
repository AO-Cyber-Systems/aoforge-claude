# TRD 37-03: Backup pruning — pure policy, throttled runner, registration

<objective>
Objective 36 writes a backup under `~/.claude/devflow/backups/<repo-slug>-<hash8>/<ts>/` before
every migration apply, and nothing ever removes them. Build the pruner as a library: a pure policy
function, a runner that applies it, a 24 h throttle, retention from global-config.json, and a repo
registry. 37-06 wires it into the SessionStart hook and the CLI.

Why SessionStart and not a scheduler (LOCKED, from OBJECTIVE.md): Claude Code has no persistent
local scheduler (`CronCreate` is session-only; `schedule`/`RemoteTrigger` run in the cloud without
`~/.claude`), so "daily" = at most once per 24 h, checked at session start.

Resolved intent: kind=plugin, work=feature, tdd=strict, test_list_first=required,
fixture_strategy=generators. Constraints honored: `no_llm_test_data`, `no_property_based_default`
(named table cases, no generators of random dates), `no_gherkin_layer`.
</objective>

<gotchas>
- `fs.rmSync(dir, {recursive: true, force: true})` per ts dir. Before removing, assert the dir is
  inside `backupsRoot(userHome)` (`path.relative` does not start with `..`) — never follow a symlink
  out: `lstat` each ts entry and skip (report in `unparsed`) anything that is not a real directory.
- Keep-min counts only PARSEABLE backups (test 11), so a stray folder can't shrink protection.
- The throttle is `now - last_prune_at < THROTTLE_MS` → throttled. A missing or unparseable stamp
  means "run" (and the run rewrites it). No clock-skew heuristics.
- Stamp write happens after the removals, even if some failed (test 15), so a permanent failure
  does not make every session retry.
- chmod-based failure tests do not work as root; `if (process.getuid && process.getuid() === 0) t.skip()`.
</gotchas>

<anti_patterns>
- Pruning by directory mtime (copying a backup would reset it). Parse the name; unparseable → keep.
- Touching `legacy-*` (it holds the user's moved legacy files) or `global-*`.
- Reading `os.homedir()` anywhere in backup-prune.cjs.
- Installing or suggesting an OS scheduler from code (OBJECTIVE: out of scope).
</anti_patterns>
