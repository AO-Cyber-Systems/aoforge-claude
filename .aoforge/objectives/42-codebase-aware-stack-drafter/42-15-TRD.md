Decided policy: repo-root commands must cover the repo's primary stack. A candidate from an
unsupported sub-area never overrides a key the resolved `extends` profile supplies; it goes to notes,

candidates may override: runner targets that run the primary language's tools, and root manifests.

the last gap cycle allowed for objective 42.

  (playwright) at the root area stay allowed as before.
