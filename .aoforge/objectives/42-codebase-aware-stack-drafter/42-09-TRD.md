# TRD 42-09: Skills + MCP wiring — `stack mcp [--write]`, agent grants, agent-side confirmation

<objective>
This TRD finishes SDR-05. The tier-2 profiles already carry `agent_tooling` (42-02), so drafts inherit
it. What's missing is:
- a deterministic generator for managed `.mcp.json` entries: `df-tools stack mcp [--write]`
- a health check for a managed server whose binary is missing
- tool grants for the agents
- an agent-side `confirm_stack_profile` step in adopt/map-codebase, which uses gopls/dart MCP tools
  when available and falls back to `stack verify --run`.

Locked decisions:
- Q4: `.mcp.json` is opt-in per repo, only via `stack mcp --write`. There is no upgrade migration and
  no `stack init --mcp`. The research proposed migration 0008. It is DROPPED because the
  `upgrade-project.js` SessionStart hook auto-applies and background-commits `auto` migrations, which
  would write `.mcp.json` fleet-wide.
- Q5: no telemetry env claims.

Output: stack-mcp.cjs, W033, agent/skill grants, workflow steps and contract tests.
</objective>

## Test list

Outermost to innermost.

1. CLI `stack mcp --raw` on a repo whose STACK.md extends `go` (bundled), with a fake PATH containing gopls: JSON `{ servers: { gopls: {command:'gopls', args:['mcp'], env:{DEVFLOW_MANAGED:'stack'}} }, skipped: [] }`, and no `.mcp.json` written.
2. CLI `stack mcp --write` with no `.mcp.json` creates one with only managed entries.
3. `--write` with an existing `.mcp.json` holding a foreign `playwright` server and a stale managed `oldtool` server: playwright is byte-identical, oldtool is removed, gopls is added. Key order is stable. Pretty JSON has 2-space indent and a trailing newline.
4. `--write` on unparseable `.mcp.json` gives exit 1, and the file is unchanged.
5. Components: root extends go, with a component `app/` with profile flutter. The servers union is gopls and dart, deduped by name, and flutter's args win for `dart`.
6. Binary missing: dart absent from the fake PATH gives `skipped: [{name:'dart', reason:'binary_missing'}]`.
7. Duplicate plugin: a fake home with `~/.claude/plugins/cache/x/dart-flutter/.claude-plugin/plugin.json` declaring `mcpServers['dart-mcp-server'] = {command:'dart', args:['mcp-server']}` means dart is skipped with reason `declared_by_plugin`.
8. No entry has any env key other than DEVFLOW_MANAGED.
9. `validate health` on a project whose `.mcp.json` has a managed `gopls` entry, with gopls absent (injected), gives W033. A foreign server with a missing binary gives no warning.
10. Contract: executor.md, verifier.md and debugger.md `tools:` include `mcp__gopls__*` and `mcp__dart__*`. The adopt/map-codebase skills' allowed-tools include both.
11. Contract: adopt.md has a `confirm_stack_profile` step ordered after scaffold and before health. It mentions `go_workspace`, `go_vulncheck`, `go_diagnostics`, `analyze_files` and `stack verify --run`, and says STACK.md is not edited silently. map-codebase.md has the same step after draft_stack_profile.
12. Contract: no migration file in `bin/lib/migrations/` references `.mcp.json`.
