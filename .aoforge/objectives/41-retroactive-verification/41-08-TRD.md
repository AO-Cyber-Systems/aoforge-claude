# TRD 41-08: Planner signals research instead of spawning it (gap VER-30)

<objective>

planner to spawn `objective-researcher` "via the standard Task(...) pattern". The planner's `tools:` declares neither
Task nor Agent, and a subagent cannot spawn subagents in Claude Code anyway, so the novel-domain auto-research path
cannot work. agent-tools.test.cjs misses this because KNOWN_TOOLS (lines 27-30) has no Task/Agent.

a signal, and the plan-objective orchestrator, which already spawns the researcher in step 6, acts on it.
