# TRD 38-09: The CI gate — no stale command reference ships

<objective>
Turn "references to renamed commands can't rot unnoticed" into a failing test. It scans every live,
DevFlow-owned text surface, including CLI fix text and hook source, with an exemption list that is
explicit, justified and checked for dead entries. It also enforces the single rename table.

Resolved intent: kind=plugin, work=feature, tdd=strict, test_list_first=required,
fixture_strategy=generators. Constraints honored: `no_llm_test_data`, `no_property_based_default`,
`no_gherkin_layer`.
</objective>

## Runtime model (binding)

- The test is read-only. The repo root is `path.resolve(__dirname, '..', '..', '..', '..', '..')`. If `README.md` is absent there (a mirror install), `t.skip('not a devflow-claude checkout')`.
- Commit via `node ~/.claude/devflow/bin/df-tools.cjs commit "<msg>" --files <paths>`. If signing fails, STOP; never bypass. One plain command per Bash call. Never use port 8080. No version bump, tag or push.

## Test list

`doc-refs.repo.test.cjs`:
1. The scan set is non-empty (> 150 files) and includes `README.md`, `plugins/devflow/devflow/bin/lib/validate.cjs` and `plugins/devflow/hooks/statusline.js`.
2. The main gate: zero findings across the scan set minus the exemptions. The failure message lists every finding and the EXEMPT table.
3. Every EXEMPT entry has a reason of ≥ 20 chars and matches ≥ 1 existing path.
4. `ignore-start` markers appear only in help.md (exactly one region, properly closed).
5. The help.md fenced table deep-equals `DEPRECATION_MAP`.
6. Sensitivity (a): route-intent.test.js and intent-fixtures.cjs each produce ≥ 1 finding when scanned directly.
7. Sensitivity (b): the sample string `/df:quick /devflow:health /devflow:update /devflow:nope /devflow:status` → kinds `[prefix, renamed, removed, unknown]`.
8. The legacy-workflow exemption is derived from frontmatter: `insert-objective.md` is exempt, and `add-objective.md` (`status: active`) is scanned.
9. `references/command-renames.json` is absent.
10. `templates/claude-md.md` and `templates/global-claude-md.md` produce zero findings. This is named separately so that a failure points straight at the files migrations 0005 and 0007 depend on.
