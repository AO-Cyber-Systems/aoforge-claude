# TRD 38-07: `lib/doc-staleness.cjs` — the four advisories

<objective>
Compute the project-documentation staleness signals in one read-only module. Every surface (health,
`validate docs`, telemetry, status) calls this module, so they can never disagree. All four signals
are advisories: a human decides, and nothing is auto-repaired.

Resolved intent: kind=plugin, work=feature, tdd=strict, test_list_first=required,
fixture_strategy=generators. Constraints honored: `no_llm_test_data` (hand-built fixture repos),
`no_property_based_default`, `no_gherkin_layer`.
</objective>

## Runtime model (binding)

- CommonJS, synchronous, no new dependencies. Git is invoked with `execFileSync('git', ['-C', root, ...])` behind a `_runGit` seam (the `_setRunFs` pattern from `project-hygiene.cjs`).
- Fixture repos come from `__fixtures__/adopt-fixtures.cjs` (`makeFixture(kind, {parent, home})`, `makeFakeHome`, `gitEnv`, `writeMappedDocs`) under mkdtemp. Extra fixture commits use `execFileSync('git', ['-C', root, 'commit', ...], {env: gitEnv(home)})`, which applies local identity and gpgsign=false. **Never touch this repo's git or any real repo.**
- Commit via `node ~/.claude/devflow/bin/df-tools.cjs commit "<msg>" --files <paths>`. If signing fails, STOP; never bypass. One plain command per Bash call. Never use port 8080. No version bump, tag or push.

## Test list

`doc-staleness.test.cjs`. Fixed `now = new Date('2026-09-28T00:00:00Z')` in every case.

W051:
1. STACK.md with `provenance: { reviewed: "2026-09-01" }` → no W051; `checked.stack_review === 'ok'`.
2. `reviewed: "2026-06-01"` (119 days) → one W051 whose message contains `119` and `90`.
3. No `provenance` → W051 `has no provenance.reviewed`. `reviewed: "someday"` → W051 `unparseable`.
4. `config.docs.stack_review_stale_days: 200` with the case-2 date → no W051.
5. No STACK.md → no W051; `skipped:no-stack`.

W052:
6. Go fixture (`go.mod`) + STACK.md `languages: [go]` → no W052.
7. Go fixture + `languages: [python]` → W052 naming `go` and `python`.
8. Node+tsconfig fixture (detects `typescript`) + `languages: [javascript]` → no W052 (alias).
9. Go fixture + STACK.md without `languages` → no W052; `skipped:no-declared-languages`.

W053 (real git in mkdtemp fixture repos):
10. `writeMappedDocs(root)` committed, then 3 commits touching `src/` → no W053 (3 ≤ 50).
11. `config.docs.codebase_map_stale_commits: 2` and the case-10 history → W053 whose message contains `3` and `2`.
12. After the map commit, 5 commits touching only `.planning/STATE.md`, threshold 2 → no W053 (`.planning` is excluded).
13. Maps written but never committed → `skipped:maps-not-committed`, no issue. A non-git dir with maps → `skipped:not-a-git-repo`.
14. `_setRunGit(() => { throw new Error('boom') })` → `skipped:git-failed`, no throw.

W050:
15. STATE.md with `run /devflow:update` in `## Current Position` → one W050. The same token only under `## Session Log` → none.
16. CLAUDE.md DEVFLOW block containing `/devflow:reapply-patches` → W050. The same token outside the block → none.
17. STATE.md with `/df:health` (renamed, not removed) → no W050.

General:
18. Every returned issue has `code`, `message` and `fix` strings and no `repairable: true`, and a snapshot of the fixture tree is byte-identical before and after `collect` (use `snapshot`/`diffSnapshots` from adopt-fixtures).

<codebase_examples>
Detectors to reuse (read 2026-09-28):

```js
// project-state.cjs re-exports repo-state's detector (validate.cjs:483 already imports it this way)
const { detectManifest } = require('./project-state.cjs');
detectManifest(root, { userHome }) // -> { has_manifest, primary_lang: 'go'|'typescript'|'javascript'|'dart'|... }

const { parseProfile } = require('./stack-profile.cjs');
parseProfile(text).frontmatter      // project file's OWN frontmatter (no extends merge — intentional:
                                    // drift is about what THIS project declared)

const managedBlock = require('./managed-block.cjs');
managedBlock.read(text)             // -> null | { meta, content, ... }; throws ManagedBlockError on malformed
```

A malformed block (ManagedBlockError) → `checked.removed_refs = 'skipped:malformed-block'`, no throw.

Session Log exclusion: split STATE.md at `/^##\s+Session Log[^\n]*$/m` (the same regex as
migration 0002) and scan only the part before it. If a later `## ` heading follows the log, scan
from that heading on as well.

Config defaults: `const DEFAULTS = { stack_review_stale_days: 90, codebase_map_stale_commits: 50 }`,
read from `config.docs`. Model this on `awareness.peer_stale_days`. Do NOT add keys to
`templates/config.json`; the defaults live in code, and 38-12 documents the overrides.
</codebase_examples>

<gotchas>
- `rev-list <sha>..HEAD` counts commits after the map commit. Pathspec `':(exclude).planning'` needs `-- .` before it.
- 38-09's CI gate scans `bin/**/*.cjs` source, comments included. Never write a literal stale token such as `/df:health` in this module's comments or strings. Write `/df:<name>` or describe it in words. Test files are exempt.
- `parseProfile` throws `StackProfileError` on a broken STACK.md. Catch it → `checked.stack_review/stack_drift = 'skipped:stack-unparseable'`. Validate's Check 12 already reports the parse error (E030), so do not double-report.
- The YAML-lite parser may return `reviewed` as a string. Parse `YYYY-MM-DD` as UTC midnight and compute whole days with `Math.floor`.
</gotchas>

<anti_patterns>
- Comparing the resolved (extends-merged) `languages`. A parent org profile's languages are not this project's declaration.
- Counting whole-repo commits: map edits and planning churn would make every map look stale.
- Adding a `--repair` path. These are advisories.
</anti_patterns>
