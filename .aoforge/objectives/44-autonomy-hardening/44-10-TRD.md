# TRD 44-10: gap closure for stale REBASE_HEAD, and naming the SUMMARY path in the gate reason

<objective>
Two fixes from verification of objective 44.

1. **Stale REBASE_HEAD.** Git leaves `.git/REBASE_HEAD` behind after a rebase completes. `gitOpInProgress()` treats it as
   "rebase in progress", so gate-commits allowed every raw commit in any repo with a stale REBASE_HEAD, including this
   checkout. A real rebase always has `rebase-merge/` or `rebase-apply/` in the git dir, and those are the only reliable signals.
2. **SUMMARY path.** The executor-stop block reason says "the TRD's SUMMARY.md". Name the concrete path, so an agent with no
   DevFlow path conventions still writes it where the gate (and the orchestrator) look.
</objective>
