<gotchas>
- **This module must NEVER throw.** Step 8c's standing contract is "NEVER a hard fail", and
  33-03 keeps that promise for `not_applicable`. If `resolveUIEvalTarget` throws on a
  missing `.planning/` directory, an unreadable file, or a garbage id, the promise breaks at
  the layer below the one that made it. Wrap every filesystem read. Case A4 pins this.
- **`fm.type !== 'ui' || fm.stack !== 'flutter'` requires BOTH.** A TRD with `type: ui` and
  no `stack` is not a Flutter UI TRD. Case A3 pins it. Getting this wrong makes every UI-ish
  objective in every repo start emitting gate output.
- **`searchObjectiveInDir` matches by prefix** (`d.startsWith(normalized)`), so the id `3`
  matches `33-...` before `3-...` depending on sort order. Pass the id through unchanged and
  let `findObjectiveInternal` own that behaviour — do not add a second normalisation. If a
  test needs an exact objective, use the full directory name.
- **Tier-3 glob order must be deterministic.** `fs.readdirSync` order is not guaranteed
  across platforms. Sort the matches lexicographically before picking `[0]`, or M3/M4 will
  be flaky on someone else's machine.
- **`fs.existsSync(arg)` is the path-vs-id discriminator, not a regex.** Do not sniff for
  `.json` in the string: `verify flutter-ui-eval 33` and
  `verify flutter-ui-eval ./manifest.json` differ by whether the argument names a file that
  exists, relative to `cwd`. Resolve relative arguments against `cwd` exactly as
  `cmdVerifyFlutterUIEval:545` already does (`path.isAbsolute(arg) ? arg : path.join(cwd, arg)`).
- **A directory is not a manifest.** `fs.existsSync` is true for directories. Check
  `statSync().isFile()`, or an argument like `.planning` resolves as a "path" and then
  explodes in `readFileSync`.
- `${PIPESTATUS[0]}` in a `verify` block: `$?` after a pipe reports the LAST command. Use
  `set -o pipefail` or `${PIPESTATUS[0]}` **inside a `bash -c '...'` wrapper** — this repo
  has a CI guard that fails on the broken form, and the interactive shell here is zsh (where
  the array is `pipestatus`), so always wrap in `bash -c`.
</gotchas>
