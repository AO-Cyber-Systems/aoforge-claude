# TRD 40-03: `intent resolve --objective <N>` finds slugged objective directories

<objective>
Defect 5 (TOOL-05): `readObjectiveMd` (intent.cjs:194-199) does an exact `path.join(..., objectiveId, 'OBJECTIVE.md')`.
A bare `40` looks for `.planning/objectives/40/OBJECTIVE.md`, misses `40-tooling-correctness/`, returns null,
and `resolve()` silently falls through to PROJECT.md `default_work` with `warnings: []`. Every
bugfix/refactor/port objective planned by bare number got the wrong TDD posture.

Fix it with a prefix match (mirroring `findObjectiveInternal` in objective.cjs:90+, re-implemented locally
because intent.cjs does not import objective.cjs), make "not found" loud, and clarify planner.md Step 1.

Resolved intent: kind=plugin, work=bugfix. Note that before this fix, `intent resolve --objective 40` reports
work=feature; the correct value is bugfix, which is what this TRD makes true.

Suggested resolver:
```js
function findObjectiveDir(projectRoot, id) {
  const base = path.join(projectRoot, '.planning', 'objectives');
  if (fs.existsSync(path.join(base, id, 'OBJECTIVE.md'))) return { dir: id, candidates: [id] };
  let dirs; try { dirs = fs.readdirSync(base, { withFileTypes: true }).filter(d => d.isDirectory()).map(d => d.name).sort(); } catch { return { dir: null, candidates: [] }; }
  const keys = [id]; if (/^\d+$/.test(id)) keys.push(id.padStart(2, '0'));
  const hits = dirs.filter(d => keys.some(k => d === k || d.startsWith(k + '-')) && fs.existsSync(path.join(base, d, 'OBJECTIVE.md')));
  return { dir: hits[0] || null, candidates: hits };
}
```
