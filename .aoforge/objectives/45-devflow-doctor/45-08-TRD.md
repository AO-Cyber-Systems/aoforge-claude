## Test list

doctor.e2e.test.cjs:
1. The report on `makeAodexLikeState()`: exit 0, `schema_version:1`, and every check id listed in must_haves is present. runtime-mirror=error, legacy-runtime-state=error, and plugin-cache, pending-migrations, skill-markers, guard-state, awareness-state and backups are warn. `summary.fixable >= 7`.
2. The report is read-only: the fixture file tree (home + project) is byte-identical before and after (hash listing).
3. `--fix`: each entry in `fixes` has `applied:true` for runtime-mirror, legacy-runtime-state, pending-migrations, skill-markers, guard-state, awareness-state and backups. The legacy fix notes contain the `df-tools commit … --files .gitignore` command.
4. The second report after (3) has `fixable === 0` and `error === 0`, and the only non-ok result is plugin-cache (warn).
5. After (3), `git ls-files` in the project lists no runtime-state path, `git check-ignore` covers the root and `flutter/` paths, and the only staged changes are those removals.
6. **SC5**: a fresh `makeAodexLikeState()` plus `src/unrelated.txt` staged, then `--fix` → legacy-runtime-state is not applied (refused or not fixable), pending-migrations is not applied (0008 pending behind the guard), and the other fixes still apply. `git diff --cached --name-only` equals `src/unrelated.txt`, and both guard files are still tracked.
7. `--global --json` runs only global checks (no legacy-runtime-state / pending-migrations / validate-health / skill-markers in `checks`).
8. The real-home canary: listings of `~/.claude/devflow/state` and `~/.claude/devflow/backups` (read-only `fs.readdirSync`, tolerating missing dirs) taken before and after the suite are equal.
