# TRD 45-01: Awareness cache leaves the repo (DOC-01)

<objective>
`awareness-cache-populate.js` rewrites `.planning/.awareness-cache.json` at session start, and
`df-tools awareness` rewrites it on every scan. This repo's copy is ~640KB. Any in-tree runtime file
gets attached to tool results by Claude Code's file watcher, and repos that committed it churn
(the quick-25 progress-guard lesson). Move the cache to
`~/.claude/devflow/state/awareness/<repo-key>.json`, with an env override for tests, and route every
reader and writer through a new builtins-only store module. Legacy fallback is deliberately omitted.
</objective>

Repo key to match exactly (`plugins/devflow/devflow/bin/lib/upgrade.cjs:217`):
```js
function repoKey(projectRoot) {
  const real = fs.realpathSync(projectRoot);
  const slug = path.basename(real).toLowerCase().replace(/[^a-z0-9]+/g, '-');
  const hash8 = crypto.createHash('sha1').update(real).digest('hex').slice(0, 8);
  return `${slug}-${hash8}`;
}
```
