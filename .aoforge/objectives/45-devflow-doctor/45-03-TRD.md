# TRD 45-03: sync-runtime re-mirrors same-version content changes (DOC-03)

<objective>
sync-runtime's early exit compares `~/.claude/devflow/.plugin-version` to the bundled version only.
A rebuilt plugin with the same version but different content, which is routine on a dev branch and
after an in-place `/plugin update` of an unreleased build, never reaches the mirror. This TRD adds a
content digest of the bundled runtime to the marker, so a same-version content change re-mirrors.
The digest lives in a shared module so doctor (45-05) computes exactly the same value.
</objective>

## Binding rules

- Strict TDD: RED before GREEN. Commit via `node /Users/justin/dev/devflow-claude/plugins/devflow/devflow/bin/df-tools.cjs commit "<msg>" --files <paths>`.
- sync-runtime tests always use a tmp plugin root and a tmp HOME (see the harness header). Never pass the real HOME or this repo as CLAUDE_PLUGIN_ROOT.
- The digest module and the hook use node builtins only (fs, path, crypto).
- Keep `.plugin-version` content as the bare version, because `validate.cjs:460` and `helpers.cjs:93` parse it as semver.
- One plain command per Bash call. Never use port 8080. Don't bump the version, tag or push.

<anti_patterns>
- Don't hash the mirror at session start to compare against the bundle. Compare the bundled digest against the `.plugin-digest` marker, which costs one tree hash of ~260 files. The doctor is what verifies real mirror content.
- Don't include mtimes, permissions or absolute paths in the digest. Relative path plus bytes only, sorted, so it is deterministic across machines.
- Don't duplicate SUBDIRS/MIRROR_EXCLUDE in the hook. Import them from runtime-digest.cjs, falling back to local literals only when the module fails to load.
- Don't write `.plugin-digest` before all subdir swaps succeed (the same rule as `.plugin-version`).
</anti_patterns>

## Test list

runtime-digest.test.cjs (hand-built temp trees):
1. `digestTree(dir)` returns a `sha256:`-prefixed string of 64 hex chars and is deterministic across two calls.
2. Changing one byte of `bin/x.cjs` changes the digest. Renaming a file changes the digest.
3. Adding `bin/lib/a.test.cjs`, `workflows/b.test.js` or `bin/lib/__fixtures__/f.json` does NOT change it.
4. Adding top-level `.plugin-version`, `.plugin-digest`, `state/…`, `stacks/…` or `backups/…` does NOT change it (only SUBDIRS count).
5. A missing subdir is treated as empty without throwing, and a missing root returns the digest of the empty set.
6. `shouldExclude` matches today's hook behavior for the listed names (regression table).
7. `readMarkerDigest(targetDir)` returns the trimmed `.plugin-digest` content or null.

sync-runtime.test.js (new describe `Objective 45: content digest marker`):
8. Fresh install writes `.plugin-digest` equal to `digestTree(pluginRoot/devflow)`, and `.plugin-version` is still the bare version.
9. Equal version + sentinel + matching digest → no-op (canary file kept).
10. Equal version + sentinel + a bundled file changed (digest differs) → re-mirror: the changed content is present in the target, the canary is gone, and the digest marker is updated.
11. Equal version + sentinel + no `.plugin-digest` (a pre-45 mirror) → re-mirror once, and a second run is a no-op.
12. Older plugin + different digest → still refused (the stderr names both versions) and the target is untouched.
13. All existing Test 1-10, Objective 34/42 and Quick 21 tests pass unchanged.
