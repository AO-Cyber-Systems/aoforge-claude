# TRD 36-02: Managed-block and notices primitives

<objective>
Two small primitives the rest of the objective composes:

1. `lib/managed-block.cjs` — the versioned `DEVFLOW:START/END` block. Today the markers are written
   only by map-codebase prose and carry no version, so nothing can tell a stale block from a current
   one. This module parses both the legacy and the versioned marker, rewrites only the bytes between
   the markers, and never touches text outside them.
2. `lib/notices.cjs` — a tiny queue of one-shot notices. The SessionStart hook (36-05) and the
   global upgrade (36-06) write to it; `route-results.js` (36-05) emits unconsumed notices once on
   the next prompt.

The plan table puts notices under 36-05. It moves here so 36-05 and 36-06 (same wave) both consume a
primitive that already exists instead of sharing a file. The scope doesn't change.

managed-block.test.cjs:
1. `read('no markers here')` → `null`.
2. Legacy start marker (exact string from `templates/claude-md.md:14`) + END → `meta = {v:null, src:null, legacy:true}`; `content` is the text between the markers minus one leading and one trailing newline.
3. `<!-- DEVFLOW:START v=2 src=claude-md -->` → `meta = {v:'2', src:'claude-md', legacy:false}`.
4. Attribute order and spacing tolerated: `<!--DEVFLOW:START src=x v=1-->` parses.
5. `render('body', {v:'2', src:'claude-md'})` → `'<!-- DEVFLOW:START v=2 src=claude-md -->\nbody\n<!-- DEVFLOW:END -->'` (trailing newlines in content collapsed).
6. Replace: `pre + legacyBlock + post` → output starts with `pre` and ends with `post` byte-for-byte; the new block is versioned.
7. CRLF: `pre`/`post` using `\r\n` are preserved exactly.
8. Append to text without a block: `'a\n'` → `'a\n\n' + block + '\n'`; `'a'` (no trailing newline) → `'a\n\n' + block + '\n'`; `''` → `block + '\n'`.
9. `position: 'prepend'` → `block + '\n\n' + text`.
10. Idempotent: `upsert(upsert(t, c, m), c, m) === upsert(t, c, m)`.
11. Two blocks → `read` throws `ManagedBlockError` with message containing `multiple`.
12. START without END → throws `ManagedBlockError` containing `unterminated`; END alone → `null`.
13. `isStale`: legacy → true; `v='1'` vs `'2'` → true; `'2'` vs `'2'` → false; `'10'` vs `'9'` → false; `'1.2'` vs `'1.10'` → true.
14. `upsert` on text whose block is malformed rethrows (never writes a second block).

notices.test.cjs:
15. `projectNoticesPath(root)` = `<root>/.planning/.devflow-notices.json`; `globalNoticesPath(home)` = `<home>/.claude/devflow/.devflow-notices.json`; `globalNoticesPath()` with no home throws.
16. `appendNotice(file, {source:'upgrade', level:'info', message:'m'}, {now})` creates parent dirs and a JSON file `{schema:1, notices:[{id, ts, source, level, message, detail:null, key:null, consumed:false}]}`.
17. Same `key` unconsumed → replaced (one entry, new message/ts); same key after consumed → new entry.
18. `takeUnconsumed([projFile, globalFile], {now})` returns notices from both files in ts order and marks them consumed; a second call returns `[]`.
19. Consumed notices older than 7 days are pruned on take; younger ones kept.
20. Missing file → `[]`; malformed JSON → `[]` and the file is left untouched (no throw).
21. Atomic write: no `*.tmp-*` file remains after append.
22. `renderNotices([...])` → starts with `## DevFlow notices`, one `- [level] message` line per notice; a `detail` string is rendered indented under its line and capped at 40 lines with `… (N more lines)`.
23. Invalid `level` (not info|warn|action) → throws on append.


<gotchas>
- Byte-exact means **slice**, never split/join lines. Compute `start` = index of the START match and
  `end` = index just past the END match; output = `text.slice(0,start) + render(...) + text.slice(end)`.
- Only an END that comes after the START closes it. An END before any START is ignored (test 12).
- `content` normalisation: strip exactly one `\n` (or `\r\n`) after the start marker and one before
  the end marker, nothing more. Render collapses trailing newlines in the new content to none and
  adds exactly one before END.
- `compareVersions`: split on `.`, compare numerically, missing parts = 0.
- Atomic write: `fs.writeFileSync(tmp)` then `fs.renameSync(tmp, file)`, with tmp in the same dir
  (`<file>.tmp-<pid>-<rand>`).
- `id`: `n-${Date.parse(ts)}-${crypto.randomBytes(3).toString('hex')}`.
</gotchas>

<anti_patterns>
- Regex-replacing the whole file (`text.replace(/START[\s\S]*END/, …)`): it is greedy across two
  blocks and hides the malformed case.
- Importing helpers.cjs or frontmatter.cjs (breaks the Node-built-ins-only rule 36-06 depends on).
- A default `userHome` of `os.homedir()` in notices.cjs.
</anti_patterns>

<error_recovery>
- A byte-preservation test fails only on CRLF → you are normalising line endings somewhere in the
  outside text; slice instead.
</error_recovery>
