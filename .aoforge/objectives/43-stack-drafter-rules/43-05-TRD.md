# TRD 43-05: Multi-stack and manifest-less roots — primary component placement (D3, D6, D2)

<objective>
One design change, the **primary component**, fixes three placement defects together:

- **D3.** A root without a manifest took a single subfolder's language: devcluster (bash + `tools/devproxy` Go) and EdenDocs (C++/JS + `wopi-host/` Go) drafted `extends: go`, with every command in the subfolder.
- **D6.** With a `general` root, any command whose effective area is a component became a note, so coverage was thin. navigators lost `just test-go`. aodex, politihub and eden-biz lost the `go/Makefile` targets.
- **D2.** In a general root, sub-area commands became root keys: aocore `bash portal/build.sh`, politihub `./build.sh` with cwd `infra/tiles`.

**User decision D3 (binding, 2026-10-02): LITERAL rule.** No root manifest ⇒ `extends: general` plus every supported area as a component. The primary component supplies root build/test/lint with cwd. Existing tests D15c (stack-draft.test.cjs), e2e 4, 11 and 14 are re-baselined to the new shape. The aoinference and opsCluster rows in 42-ROLLOUT.md are regression targets under the new shape.
**User decision (binding): primary-component tie-break is go-first.** It is a heuristic, so document it in code and test it.

Output: the placement rework in stack-draft.cjs (pure), the effective-area facts in stack-evidence.cjs, re-baselined tests, and focused e2e shapes. The full 11-golden suite is 43-06.
</objective>

<anti_patterns>
- A stack-family gate on general roots that drops shell/neutral root commands. devcluster's `shellcheck` / `bash t0-conformance/selftest.sh` and EdenDocs's `./scripts/eden/build.sh` are correct root keys. Only a root candidate whose tool stack is a NON-primary component's stack (for example `flutter build` at root when the primary is go) becomes an `off_primary` note.
- A pseudo-area for root-level helper dirs that legitimately run root commands. Apply it only when the cwd is non-root and not under a language area (Pitfall 3), and keep a `sub_area` note so nothing is lost silently.
- Tier-default fallback in multi-component repos. politihub, aodex and eden-biz goldens have NO lint. Fallback applies only when there is exactly one component.
- Re-emitting format/fix/audit/codegen/tidy at the root with cwd. In the new shape, the component inherits them from its tier.
</anti_patterns>
