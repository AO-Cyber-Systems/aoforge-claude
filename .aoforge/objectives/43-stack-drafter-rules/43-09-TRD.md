# TRD 43-09: Evidence-shape fixes from real repos (Make comments, drift checks, CI env, version probes)

<objective>
Fix the four evidence-level defects the real fleet exposed, where the drafter never saw the right candidate or saw a wrong one:

1. A Makefile help comment containing `;` creates fake recipe units (`; idempotent`, `; biz-api stays up`), which moves a target's effective area.
2. Real drift checks are written as a captured `git diff` or a snapshot `diff -q`, not `git diff --exit-code`. As a result, `fmt-check`, `tidy-check` and `openapi-verify`-shaped targets are dropped or classed as generators.
3. Workflow-level `env:` literals are not substituted, so `helm lint "${CHART_DIR}/"` cannot equal the reviewed `helm lint helm/aocore-gateway/`.
4. `kubeconform -v` in an install step is taken as the `lint_helm` gate.

Purpose: closes the devflowops `format`/`tidy`, aodex `codegen` and aocore `lint_helm` rows, and removes the fake-unit noise eden-biz's `e2e_env` row depends on (closed in 43-10/43-11).
Output: rule fixes in stack-runners, stack-ci, stack-classify and stack-evidence, the realshape fixture module and suite (created here, extended by 43-10..43-13), and KNOWN_DRIFT minus four rows.
</objective>

<anti_patterns>
- Building the fixture from the drafter's current output, or with a `git diff --exit-code` recipe "because that is what the rule reads". The fixture must carry the REAL shape (captured diff, snapshot `diff -q`) with invented names and bodies.
- Matching the target name `openapi-verify` or a chart path in a rule. Rules read structure: a check suffix, a writer followed by a diff and `exit 1`, an `env:` literal.
- Substituting `${{ … }}` expressions or step-local variables. Only literal `env:` scalars are substituted. Runtime values stay as they are.
- Unquoting a word that still contains whitespace, `*`, `?`, `$`, `;`, `|`, `&`, `<` or `>` after substitution.
</anti_patterns>

<error_recovery>
- If widening `isDriftCheck` makes a non-check target (a target that only prints a diff) into a check form, require that the recipe fails on the diff (`exit 1`, `exit $$rc`, `false`, `|| exit`), and add that negative case to the test list.
- If env substitution changes a currently matching repo's draft, inspect that repo's committed value. If the committed file carries the literal `${VAR}`, keep the raw text for that case (for example, when the variable is redefined later in the job) and record it.
</error_recovery>
