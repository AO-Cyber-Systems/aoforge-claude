# TRD 43-11: Aggregates, codegen target choice and environment targets

<objective>
Fix root causes (iii), (iv) and (v) on the real shapes:
- justinforme and smartWellness: `generate: proto sqlc gen-dart` wins codegen by name, but the aggregate also pulls deps (`dart pub get`) and lint (`dart analyze`) through `gen-dart`. The reviewed choice is the pure leg `make proto`.
- eden-biz: the go component's `generate: templ tailwind buf-generate` is right, but a `templ-check` drift check that covers only the templ leg would turn it into an apply.
- eden-biz: `e2e-stack-down` competes with `e2e-stack-up` for `e2e_env`, and `e2e-db-reset` (an env reset) is drafted as `e2e`.
- ao-terminal: `task init` (internal npm install + go mod tidy) is drafted as `deps` over CI's `npm ci …`.

Purpose: closes justinforme.codegen, smartWellness.codegen, eden-biz.codegen and eden-biz.e2e_env, and removes the bootstrap-as-deps class (ao-terminal).
Output: `unitKeys` and leg facts in stack-evidence, the teardown/reset tokens in stack-classify, three draft rules, and four realshape fixtures.
</objective>

<anti_patterns>
- Ranking `make proto` first because it is the default goal or because of its name. The rule is structural: the aggregate mixes keys, so its pure legs win.
- Treating every target with a `cd` outside the repo as external and dropping it. That would drop `deps: make gen-dart`, which the reviewed file keeps.
- Making `seed` a teardown or reset token. 43-04 tests use `e2e:seed` as a bring-up.
- Stripping `--no-audit --no-fund` to reach the reviewed `npm ci`. That rewrites evidence. Record the residual instead.
</anti_patterns>
