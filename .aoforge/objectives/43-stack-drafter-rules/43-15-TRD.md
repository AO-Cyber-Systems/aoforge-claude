# TRD 43-15: Final fleet dry run, residual decision, and docs

<objective>
Measure gap cycle 1 the way 43-07 measured cycle 0: a read-only fleet dry run against every committed STACK.md. Then put every row that still differs in front of the user, and ship the changelog.

Target: no conflict rows except ACCEPTED ones. Where a row cannot be closed by a general rule (expected candidates: ao-terminal `deps` and aocore `test`, both flag-only hand edits that the verbatim principle forbids the drafter to make), say so explicitly and list the row for user acceptance. Never add a repo-named rule to close a row.

Output: a new 43-ROLLOUT.md section, final ACCEPTED/OPEN tables with KNOWN_DRIFT removed, a CHANGELOG entry, and a green `npm test`.
</objective>

## Binding rules

- READ-ONLY across the fleet: `stack init` only, with no `--write`, no `--run`, no gates and no commits in any fleet repo. Git `rev-parse`/`status`/`show`/`hash-object` (no `-w`) with `GIT_OPTIONAL_LOCKS=0`. Out of scope: re-running `stack verify --run` (it needs a fresh fleet approval and a host cgo linker fix).
- Use the CHECKOUT df-tools and the 43-08 `compareDrift` helper, so the table and the harness can never disagree.
- The decision is the user's. Before the checkpoint, only 43-ROLLOUT.md may change.
- Never port 8080. One plain command per Bash call. Commit with `df-tools commit --files`.

Expected residual candidates if 43-11/43-13 re-tagged them:
- ao-terminal.deps: committed `npm ci` vs draft `npm ci --no-audit --no-fund`. CI only ever runs the flagged form, and the reviewed value dropped the flags by hand.
- aocore.test: committed `go test -short -race ./... -timeout 5m` vs draft `go test -short ./... -race -coverprofile=coverage.out -timeout 5m` (cwd go). Flag order and the coverage flag were edited by hand.

For each, the user's options at the checkpoint are: (a) accept, so the row joins ACCEPTED with the reason "hand-edited flags; drafter stays verbatim"; (b) leave it open as a gap for the verifier; or (c) refresh that repo's committed file to the draft value later. Option (c) is a separate approval and a commit in that repo, NOT done in this TRD.
</codebase_examples>

<anti_patterns>
- Counting a row as match because it is in KNOWN_DRIFT. KNOWN_DRIFT is a ratchet, not an acceptance.
- Folding OPEN into ACCEPTED to make the success line read "met". OPEN rows keep the objective at gaps_found for the verifier.
- Editing any drafter module here. A rule found missing at this stage goes into the SUMMARY as a follow-up.
</anti_patterns>

<error_recovery>
- If the dry run shows a NEW conflict in a repo that matched at 43-07 or 43-08, and the harness did not fail on it, the repo changed since: compare its HEAD with the 43-08 record. Report it as `repo changed` with both HEADs. Do not fix the drafter here.
- If a fleet repo's signature changes during the run, stop the run and report the delta. The dry run must be read-only.
</error_recovery>
